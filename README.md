## Prerequisites
- Visual Studio (2019/2022) with "Desktop development with C++" workload
- CMake (recommended >= 3.20)
- Git
- natID (if you are building GUI parts that depend on it) — ensure headers/libs are available or update CMake include paths accordingly

## Quick setup (recommended, PowerShell)
Clone the repository and build with CMake + Visual Studio from PowerShell. Replace the Visual Studio generator if you use a different version.

```powershell
# from a directory where you want the repo
git clone https://github.com/vrosi21/DSAI_AI_Project_The_Travelling_Salesman.git
cd DSAI_AI_Project_The_Travelling_Salesman

# create an out-of-source build and configure for Visual Studio 2022 x64
cmake -S . -B build -G "Visual Studio 17 2022" -A x64

# build (Release)
cmake --build build --config Release
``` 

## Project hierarchy

Top-level folders (tree shows only folders and top-level files):

```
The_Travelling_Salesman/
├─ CMakeLists.txt
├─ TTS.cmake
├─ README.md
├─ Documentation.md
├─ res/
├─ include/
├─ src/
└─ build/
```

Components (short explanations):

- `CMakeLists.txt` — Top-level CMake file that configures the solution and loads `TTS.cmake`.
- `TTS.cmake` — Project fragment that lists sources and sets up the target; it now adds `include/` to the compiler include path.
- `res/` — Resources such as images and translation XMLs (`res/tr/EN/main.xml`, `res/tr/BA/main.xml`).
- `include/` — Public headers for UI components and app wiring. Place new public headers here (e.g., `MapView.h`, `SidePanelView.h`, `MainWindow.h`).
- `src/` — Implementation `.cpp` files (entry point `main.cpp`, `MapView.cpp`, `SidePanelView.cpp`, etc.).
- `build/` — Out-of-source build directory autogenerated by CMake (ignored by VCS).

If you want more detail for any folder or file (examples, build notes, or where to find UI strings), tell me which part and I'll expand it.
